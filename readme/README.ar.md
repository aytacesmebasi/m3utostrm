<h1 align="center">M3U to STRM Converter</h1>

<p align="center">
  <strong>أداة قوية لتحويل قوائم IPTV M3U إلى ملفات STRM لمراكز الميديا مثل Kodi و Jellyfin.</strong>
</p>

## المميزات
- **إنشاء STRM تلقائي:** يحول الروابط إلى ملفات STRM.
- **صور وبيانات وصفية:** يقوم بتنزيل ملفات .nfo والملصقات.
- **مطابقة ذكية:** يستخدم خوارزميات للبحث في TMDb.
- **لغات متعددة:** الواجهة متوفرة بـ 13 لغة.
- **استئناف المعالجة:** يتذكر التقدم ويتجنب التكرار.
- **مزامنة تلقائية:** تحديث يومي في الخلفية.

## التثبيت
1. استنساخ المستودع: `git clone https://github.com/aytacesmebasi/m3utostrm.git`
2. تثبيت المتطلبات: `pip install -r requirements.txt` (أو تشغيل install.bat)
3. تشغيل البرنامج: `python main.py`

## الاستخدام
1. انتقل إلى علامة التبويب **الإعدادات**.
2. أدخل تفاصيل IPTV الخاصة بك.
3. أدخل مفاتيح API الخاصة بك.
4. ابدأ المعالجة.
