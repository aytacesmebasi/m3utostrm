<h1 align="center">M3U to STRM Converter</h1>

<p align="center">
  <strong>Ein leistungsstarkes Tool, um IPTV M3U-Playlists mit umfangreichen TMDb-Metadaten in STRM-Dateien für Kodi, Jellyfin und Emby zu konvertieren.</strong>
</p>

## Eigenschaften
- **Automatische STRM-Erstellung:** Konvertiert M3U-Links in STRM-Dateien (organisiert nach Filme, Serien und XXX).
- **Umfangreiche Metadaten & Bilder:** Lädt .nfo-Dateien, Poster, Fanarts, Logos, Discarts und Thumbnails herunter.
- **Intelligente Zuordnung:** Nutzt fortschrittliche Algorithmen, um Namen mit TMDb abzugleichen.
- **Mehrsprachig:** Oberfläche in 13 Sprachen verfügbar.
- **Fortsetzbare Verarbeitung:** Merkt sich den Fortschritt und vermeidet Duplikate.
- **Auto-Sync:** Hintergrund-Automatisierung für tägliche Aktualisierungen.

## Installation
1. Repository klonen: `git clone https://github.com/aytacesmebasi/m3utostrm.git`
2. Abhängigkeiten installieren: `pip install -r requirements.txt` (oder install.bat unter Windows ausführen)
3. Anwendung starten: `python main.py`

## Verwendung
1. Gehen Sie zum Reiter **Einstellungen**.
2. Geben Sie Ihre IPTV-Daten ein oder wählen Sie eine lokale M3U-Datei.
3. Geben Sie Ihre TMDB- und Fanart.tv-API-Schlüssel ein.
4. Gehen Sie zum Reiter **M3U Processing Engine** und klicken Sie auf **Verarbeitung starten**.
