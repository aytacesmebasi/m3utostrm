<h1 align="center">M3U to STRM Converter</h1>

<p align="center">
  <strong>Una poderosa herramienta para convertir tus listas M3U de IPTV en archivos STRM para centros multimedia como Kodi, Jellyfin y Emby con metadatos de TMDb.</strong>
</p>

## Características
- **Generación automática de STRM:** Convierte enlaces M3U a STRM organizados por Películas, Series y XXX.
- **Metadatos e Imágenes:** Descarga archivos .nfo, pósteres, fanarts, logos, discarts y miniaturas.
- **Coincidencia Inteligente:** Usa algoritmos avanzados para emparejar nombres complejos con TMDb.
- **Soporte Multilingüe:** Interfaz disponible en 13 idiomas.
- **Procesamiento Reanudable:** Recuerda el progreso y evita duplicar archivos.
- **Sincronización Automática:** Automatización en segundo plano para actualizar diariamente.

## Instalación
1. Clona el repositorio: `git clone https://github.com/aytacesmebasi/m3utostrm.git`
2. Instala las dependencias: `pip install -r requirements.txt` (o ejecuta install.bat en Windows)
3. Ejecuta la aplicación: `python main.py`

## Uso
1. Ve a la pestaña **Configuración**.
2. Introduce tus datos de IPTV o selecciona un archivo M3U.
3. Introduce tus claves de API de TMDB y Fanart.tv.
4. Ve a la pestaña **Motor de Procesamiento M3U** y haz clic en **Iniciar Procesamiento**.
