<h1 align="center">M3U to STRM Converter</h1>

<p align="center">
  <strong>Un outil puissant pour convertir vos listes de lecture IPTV M3U en fichiers STRM pour Kodi, Jellyfin et Emby avec les métadonnées TMDb.</strong>
</p>

## Fonctionnalités
- **Génération automatique de STRM:** Convertit les liens M3U en fichiers STRM (Films, Séries et XXX).
- **Métadonnées et Images:** Télécharge les fichiers .nfo, affiches, fanarts, logos, discarts.
- **Correspondance Intelligente:** Algorithmes avancés pour faire correspondre les noms avec TMDb.
- **Multilingue:** Interface en 13 langues.
- **Reprise du traitement:** Mémorise la progression et évite les doublons.
- **Synchronisation Auto:** Mise à jour automatique quotidienne en arrière-plan.

## Installation
1. Cloner le dépôt: `git clone https://github.com/aytacesmebasi/m3utostrm.git`
2. Installer les dépendances: `pip install -r requirements.txt` (ou exécutez install.bat sur Windows)
3. Lancer l'application: `python main.py`

## Utilisation
1. Allez dans l'onglet **Paramètres**.
2. Entrez vos informations IPTV ou sélectionnez un fichier M3U.
3. Entrez vos clés API TMDB et Fanart.tv.
4. Allez dans l'onglet **Moteur de traitement M3U** et cliquez sur **Démarrer**.
