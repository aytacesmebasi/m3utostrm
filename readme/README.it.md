<h1 align="center">M3U to STRM Converter</h1>

<p align="center">
  <strong>Un potente strumento per convertire le playlist IPTV M3U in file STRM per Kodi, Jellyfin ed Emby con metadati TMDb.</strong>
</p>

## Caratteristiche
- **Generazione automatica STRM:** Converte i link M3U in STRM (Film, Serie, XXX).
- **Metadati e Immagini:** Scarica file .nfo, poster, fanart, loghi e miniature.
- **Abbinamento Intelligente:** Usa algoritmi avanzati per cercare i nomi su TMDb.
- **Multilingua:** Interfaccia disponibile in 13 lingue.
- **Elaborazione Riprendibile:** Ricorda dove si era interrotto ed evita file duplicati.
- **Auto-Sync:** Aggiornamento automatico giornaliero in background.

## Installazione
1. Clona il repository: `git clone https://github.com/aytacesmebasi/m3utostrm.git`
2. Installa le dipendenze: `pip install -r requirements.txt` (o esegui install.bat su Windows)
3. Avvia l'applicazione: `python main.py`

## Utilizzo
1. Vai alla scheda **Impostazioni**.
2. Inserisci i tuoi dati IPTV o seleziona un file M3U locale.
3. Inserisci le tue chiavi API TMDB e Fanart.tv.
4. Vai alla scheda **Motore di Elaborazione M3U** e clicca su **Inizia Elaborazione**.
