<h1 align="center">M3U to STRM Converter</h1>

<p align="center">
  <strong>IPTV M3UプレイリストをKodi、Jellyfin、Emby用のSTRMファイルに変換する強力なツールです。</strong>
</p>

## 機能
- **自動STRM生成:** M3UリンクをSTRMファイルに変換します。
- **豊富なメタデータ:** .nfoファイル、ポスター、ロゴなどをダウンロードします。
- **スマートマッチング:** TMDbで高度なアルゴリズムを使用します。
- **多言語対応:** 13言語で利用可能です。
- **再開可能な処理:** 進行状況を記憶し、重複を避けます。
- **自動同期:** バックグラウンドで毎日同期します。

## インストール
1. リポジトリのクローン: `git clone https://github.com/aytacesmebasi/m3utostrm.git`
2. 依存関係のインストール: `pip install -r requirements.txt` (Windowsの場合はinstall.batを実行)
3. アプリケーションの実行: `python main.py`

## 使い方
1. **設定**タブに移動します。
2. IPTVの詳細を入力するか、M3Uファイルを選択します。
3. TMDBとFanart.tvのAPIキーを入力します。
4. **処理開始**をクリックします。
