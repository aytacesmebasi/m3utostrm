<h1 align="center">M3U to STRM Converter</h1>

<p align="center">
  <strong>IPTV M3U 재생 목록을 Kodi, Jellyfin 및 Emby용 STRM 파일로 변환하는 강력한 도구입니다.</strong>
</p>

## 특징
- **STRM 자동 생성:** M3U 링크를 STRM 파일로 변환합니다.
- **풍부한 메타데이터:** .nfo 파일, 포스터, 로고 등을 다운로드합니다.
- **스마트 매칭:** TMDb와 일치시키는 고급 알고리즘을 사용합니다.
- **다국어 지원:** 13개 언어로 제공됩니다.
- **재개 가능한 처리:** 진행 상황을 기억하고 중복을 방지합니다.
- **자동 동기화:** 백그라운드에서 매일 동기화합니다.

## 설치
1. 저장소 복제: `git clone https://github.com/aytacesmebasi/m3utostrm.git`
2. 종속성 설치: `pip install -r requirements.txt` (또는 install.bat 실행)
3. 응용 프로그램 실행: `python main.py`

## 사용법
1. **설정** 탭으로 이동합니다.
2. IPTV 세부 정보를 입력하거나 M3U 파일을 선택합니다.
3. API 키를 입력합니다.
4. **처리 시작**을 클릭합니다.
