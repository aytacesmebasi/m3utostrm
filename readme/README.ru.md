<h1 align="center">M3U to STRM Converter</h1>

<p align="center">
  <strong>Мощный инструмент для преобразования плейлистов IPTV M3U в файлы STRM для Kodi, Jellyfin и Emby с метаданными TMDb.</strong>
</p>

## Особенности
- **Автоматическое создание STRM:** Преобразует ссылки M3U в файлы STRM.
- **Метаданные и Изображения:** Загружает файлы .nfo, постеры, фанарты, логотипы.
- **Умный поиск:** Использует продвинутые алгоритмы для сопоставления с TMDb.
- **Мультиязычность:** Интерфейс на 13 языках.
- **Возобновление работы:** Запоминает прогресс и избегает дублирования.
- **Авто-Синхронизация:** Ежедневное обновление в фоновом режиме.

## Установка
1. Клонировать репозиторий: `git clone https://github.com/aytacesmebasi/m3utostrm.git`
2. Установить зависимости: `pip install -r requirements.txt` (или запустить install.bat на Windows)
3. Запустить приложение: `python main.py`

## Использование
1. Перейдите на вкладку **Настройки**.
2. Введите данные IPTV или выберите локальный файл M3U.
3. Введите ваши ключи API TMDB и Fanart.tv.
4. Перейдите на вкладку **Обработка M3U** и нажмите **Начать**.
