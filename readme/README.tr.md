<h1 align="center">M3U to STRM Converter</h1>

<p align="center">
  <strong>IPTV M3U oynatma listelerinizi TMDb meta verileriyle Kodi, Jellyfin ve Emby gibi medya merkezleri için STRM dosyalarına dönüştüren güçlü bir araç.</strong>
</p>

## Özellikler
- **Otomatik STRM Oluşturma:** M3U linklerini Filmler, Diziler ve XXX olarak klasörleyerek STRM dosyalarına dönüştürür.
- **Gelişmiş Meta Veri ve Görseller:** .nfo dosyaları, posterler, fanartlar, logolar, disk artları ve küçük resimler indirir.
- **Akıllı Eşleştirme:** Bozuk veya karmaşık film/dizi isimlerini TMDb ile eşleştirmek için gelişmiş algoritmalar kullanır.
- **Çoklu Dil Desteği:** Arayüz 13 farklı dilde kullanılabilir.
- **Kaldığı Yerden Devam Etme:** Nerede kaldığını otomatik hatırlar ve var olan dosyaları tekrar indirmeyi önler.
- **Otomatik Senkronizasyon:** STRM kütüphanenizi her gün belirli bir saatte güncel tutmak için arka planda otomatik çalışır.

## Kurulum
1. Depoyu klonlayın: `git clone https://github.com/aytacesmebasi/m3utostrm.git`
2. Gereksinimleri yükleyin: `pip install -r requirements.txt` (veya Windows üzerinde install.bat çalıştırın)
3. Uygulamayı başlatın: `python main.py`

## Kullanım
1. **Ayarlar** sekmesine gidin.
2. IPTV bilgilerinizi (URL, kullanıcı adı, şifre) girin veya yerel bir M3U dosyası seçin.
3. TMDB ve Fanart.tv API anahtarlarınızı girin.
4. **M3U İşleme Motoru** sekmesine gidip **İşlemi Başlat** butonuna tıklayın.
