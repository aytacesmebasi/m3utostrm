<h1 align="center">M3U to STRM Converter</h1>

<p align="center">
  <strong>Потужний інструмент для перетворення списків IPTV M3U у файли STRM для Kodi, Jellyfin та Emby.</strong>
</p>

## Особливості
- **Автоматичне створення STRM:** Перетворює посилання M3U у файли STRM.
- **Метадані та Зображення:** Завантажує файли .nfo, постери, фанарти, логотипи.
- **Розумний пошук:** Використовує алгоритми для пошуку в TMDb.
- **Багатомовність:** Інтерфейс доступний 13 мовами.
- **Відновлення роботи:** Запам'ятовує прогрес.
- **Авто-Синхронізація:** Щоденне оновлення у фоновому режимі.

## Встановлення
1. Клонувати репозиторій: `git clone https://github.com/aytacesmebasi/m3utostrm.git`
2. Встановити залежності: `pip install -r requirements.txt` (або запустити install.bat (Windows))
3. Запустити програму: `python main.py`

## Використання
1. Перейдіть на вкладку **Налаштування**.
2. Введіть дані IPTV або виберіть локальний файл M3U.
3. Введіть ключі API TMDB та Fanart.tv.
4. Перейдіть на вкладку **Обробка M3U** і натисніть **Почати**.
