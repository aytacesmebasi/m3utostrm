<h1 align="center">M3U to STRM Converter</h1>

<p align="center">
  <strong>一个将IPTV M3U播放列表转换为Kodi、Jellyfin和Emby的STRM文件的强大工具。</strong>
</p>

## 特点
- **自动生成STRM:** 将M3U链接转换为STRM文件。
- **丰富的元数据:** 下载.nfo文件、海报、同人画等。
- **智能匹配:** 使用高级算法在TMDb中匹配。
- **多语言支持:** 提供13种语言。
- **可恢复的处理:** 记住进度，避免重复。
- **自动同步:** 每天后台自动同步。

## 安装
1. 克隆仓库: `git clone https://github.com/aytacesmebasi/m3utostrm.git`
2. 安装依赖: `pip install -r requirements.txt` (或运行 install.bat)
3. 运行应用: `python main.py`

## 使用
1. 前往 **设置** 选项卡。
2. 输入您的IPTV详细信息或选择本地M3U文件。
3. 输入您的API密钥。
4. 点击 **开始处理**。
