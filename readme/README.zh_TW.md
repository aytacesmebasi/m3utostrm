<h1 align="center">M3U to STRM Converter</h1>

<p align="center">
  <strong>一個將IPTV M3U播放清單轉換為Kodi、Jellyfin和Emby的STRM文件的強大工具。</strong>
</p>

## 特點
- **自動生成STRM:** 將M3U連結轉換為STRM文件。
- **豐富的元數據:** 下載.nfo文件、海報、同人畫等。
- **智能匹配:** 使用高級算法在TMDb中匹配。
- **多語言支持:** 提供13種語言。
- **可恢復的處理:** 記住進度，避免重複。
- **自動同步:** 每天後台自動同步。

## 安裝
1. 克隆倉庫: `git clone https://github.com/aytacesmebasi/m3utostrm.git`
2. 安裝依賴: `pip install -r requirements.txt` (或運行 install.bat)
3. 運行應用: `python main.py`

## 使用
1. 前往 **設置** 選項卡。
2. 輸入您的IPTV詳細信息或選擇本地M3U文件。
3. 輸入您的API密鑰。
4. 點擊 **開始處理**。
